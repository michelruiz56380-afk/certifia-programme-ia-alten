# Programme de la formation IA Alten

Page web du programme des 17 et 18 novembre 2026 (Certif-IA), animée par Michel Ruiz.

- `index.html` : la page publiée (autonome, logos intégrés en base64)
- `Programme_Formation_IA_Alten.pdf` : la version imprimable (A4, 4 pages)
- `src/programme.tpl.html` : le gabarit source, dont les logos sont remplacés au moment de la génération

Les liens vers les supports sont bloqués en JavaScript jusqu'au 19 novembre 2026 à 0 h (heure de Paris). Avant cette date, un clic affiche un message.

Déploiement : Netlify, publication du dossier racine (voir `netlify.toml`), sans étape de build.
